# 路径表示说明

本仓库公开的两份Markdown使用三个明确的工程根占位符，分别保留Windows单反斜杠、JSON双反斜杠和正斜杠表示。它们仅替代维护者电脑上的绝对工程根目录，后续相对路径、源ID、原行指纹和证据内容保持。

`path_filter.py` 是本仓库必要的Git输入／输出辅助工具，不是酒馆扩展程序。只转换标准输入中的已指定工程根表示，从标准输出返回，不读写地点文件、不联网、不改生成检查程序。

维护者原地工作库配置该过滤器：提交时转换成公开占位符，取回时还原为原工程根。本机原位两份Markdown保持受审字节，初次入库逐文件验证转换后再还原的SHA与原文件完全一致。完整配置及恢复信息保留在维护者本机实施记录。

普通协作者不需要配置过滤器，编辑资料的人类字段即可。不要改占位符、来源元数据、只读基线引用或表头；它们用于维护者还原来源后按既有合同校验。若要迁移完整生成环境，由维护者另行配置，不把占位符当作可下载网址。

Git版本是同一份事实主档的传输表示，不另维护一份导出的可编辑资料库。证据附件、原分片与只读baseline并未全部随库公开；需核材料时按记录中的来源ID和文件名联系维护者。
